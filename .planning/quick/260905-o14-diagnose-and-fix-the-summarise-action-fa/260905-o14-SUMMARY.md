## Root Cause

Credential validation succeeded because it uses `GET /openai/v1/models`, but summary generation used a hard-coded model that Groq shut down on July 17, 2026. Chat-completion rejection was then collapsed into `GROQ_UNAVAILABLE`, so the popup incorrectly claimed an internet-connectivity failure.

The causal toggle kept the endpoint, messages, limits, and request count unchanged: the retired model produced HTTP 400 `invalid_request_error` with the allowlisted `model_decommissioned` classification, while the recommended model produced HTTP 200 with non-zero output. Reverting only the model restored the same HTTP 400 class. A single request reproduced the failure, excluding three-request concurrency as the principal cause; two direct HTTPS probes received HTTP responses, excluding transport as the principal cause.
